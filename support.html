支持的设备

💻 桌面 / 笔记本
  • · 屏幕宽度 ≥ 1280px 体验最佳
  • · 系统：Windows 10/11、macOS 10.15+
  • · 内存 ≥ 4GB
📱 手机 / 平板
  • · iPhone：iOS 13.4 及以上（SE 及更新）
  • · 安卓：Android 8.0 及以上
  • · 屏幕宽度 ≥ 360px（再窄会挤压）

网络与浏览器设置

  • 🌐 必须联网：网站依赖 Tailwind CDN、Font Awesome 图标、Google Fonts 在线加载
  • 📶 建议带宽：4G / WiFi；首屏约 1-2MB，图片懒加载
  • ⚙️ 开启 JavaScript：购票、值机、会员等所有交互均由 JS 驱动
  • 🔐 允许本地存储（localStorage）：订单、会员等级、兑换记录保存在本机；无痕模式下数据不保留
  • 🔊 如需背景音乐：浏览器需允许自动播放/用户手势触发音频

如何判断自己的设备是否支持

  1. 看上面"我的设备自检"卡片：本站已自动读取你的浏览器类型、版本、操作系统，并给出"✅ 推荐访问"或"⚠️ 建议升级"的结论。
  2. 视觉自检：如果首页有明显的毛玻璃模糊效果（导航栏、卡片背景半透明）、标题圆润饱满、滚动时模块依次滑入浮现，说明你的浏览器支持完整效果。
  3. 功能自检：尝试点击顶部导航、首页热门航线卡片切换标签——若能正常点击、切换、跳转，说明 JS 与交互正常。
  4. 升级浏览器：若页面错位、模糊消失、按钮无反应，请到浏览器官网下载最新版（Chrome / Edge / Safari 均为免费自动更新）。
